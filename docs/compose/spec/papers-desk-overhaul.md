# Phase 5：市长办公桌 · Papers Please 式深度重构

## Report

（实现完成后填写）

## [S1] Problem

玩家实测反馈：「极其差，极其粗糙」「文字和流水线一样」「UI 极差」「玩了几周（游戏内）就再也玩不下去」。

根因不是模拟内核缺失，而是**体验层三重失败**：

1. **幻想错位**——产品承诺「在真实运行的社会中经历自己的人生」，交付的却是「科员事件点击器」。档案美学是正确直觉，但没有刀子，变成读公文回忆录。
2. **文字流水线**——事件是 2–4 句干瘪说明＋抽象选项；PC 无内心、NPC 无具体感、后果多为数值；序章仅一段话。
3. **UI 是网页文章**——单栏卡片＋侧栏页签，2400 行 `UiRoot` 整树重建；状态是进度条堆，不是工作台。

同时，原 23 岁科员开局与「七品地级市主官」的高级干部幻想不匹配（用户已拍板改七品开局）。品秩、机构、人事须严格按世界观总设定【核心正式设定】。

## [S2] Design

### S2.0 已锁定决策（Grill 结论）

| 轴 | 结论 |
| --- | --- |
| 重构深度 | **重做内容＋UI＋体验层，保留模拟内核**（Flow 调度/marks/echo/clock 可迁移） |
| 体验对标 | **Papers Please 式程序压力**——每份材料都可能出事 |
| 文字策略 | **手写精品＋LLM 日常个性化** |
| 压力玩法 | **卷宗签批回合制**（无真实倒计时；关键日可加强张力） |
| UI 呈现 | **程序美学升级为市长办公桌**（零外部美术资产） |
| 起点 | **七品·普通地级市主官**（市长），机构人事严格按世界观 |

### S2.1 幻想一句话

**你是云中市市长（七品·正厅）。每天，文件堆在你桌上。签对了，城市转下去；签错了，有人进纪委，或者你进。十年后，你要么去更好的地方，要么安全着陆，要么落马。**

### S2.2 世界观锚点（冻结，只读引用）

来源：`E:\AI\帝国\设定\中华帝国世界观总设定v2.0.md`【核心正式设定】

- **七品＝正厅局级＝普通地级市主官、省直厅局正职**；官阶一品至十品；十品以下为吏三等。晋升七品需帝国考试（高等级）＋中央组织委员会备案，正式进入高级干部序列。
- **市政府组成机关 19 局**：财政、教育、公安、民政、司法、人社、自然资源、住建、交通、卫生健康、应急管理、市场监管、审计、城市管理、文化旅游、统计、医保、退役军人、宣传。
- **政治口**：市人民政治委员会常务委员会（11 席，单数 7–11）、市组织部、市纪委、市监委。
- **常委会席位**：①主席（兼议会常委会主席）②副主席·市长 ③副主席·组织部部长 ④市纪委主席 ⑤市监委主席 ⑥市法院院长 ⑦市检察院检察长 ⑧市审计局局长 ⑨秘书长/办公厅主任 ⑩国防动员办公室主任 ⑪市政府所在区主官。
- **命名纪律**：州＝部、省＝署、市＝局、区＝局/科；机关内无政党。
- **城市分档**：副省级市六品、普通地级市七品、县级市九品；京畿直隶州高一品。
- **AI 时代口径**（编年史/小说）：算法可提供意见，不得代替法定权力主体作最终决定——**市长签批权是不可让渡的刀子**。

### S2.3 舞台：云中市（普通地级市·七品）

- **选定城市**：**华北州·山西省·大同市**（世界线内真实存在；煤炭老工业基地转型，符合「产业阵痛＋AI 野心」压力源）。文案中可用「云中」为古称/市井别称增加质感，法律与公文用正式名「大同市」。
- **若作者否决**：换任一华北/江南普通地级市即可，架构不绑死城名；常量集中在 `State.NewGame`。
- **压力源（叙事种子，不改设定）**：财政吃紧、煤电转型、省里 AI 产业园指标、征地与信访、巡视整改存量、常委会内部角力。

### S2.4 玩家角色与开局

| 项 | 设定 |
| --- | --- |
| 职务 | 大同市人民政府市长（七品·正厅；常委会副主席） |
| 年龄 | **41 岁**（1985 年生，2026-09 就任）——世界观最快合规轨 |
| 履历钩子 | 出身三选一＋**三次提前考核特批**写入 marks——荣光也是巡视靶子（「晋升是否过快」） |
| 家庭 | 配偶 39–42（市属单位/国企）；一子女约 16–19（高中或大一）；父母 65–72，一方慢病 |
| 政治债务 | 就任前 1–2 个「谁把你放到这个位子上」的暗 mark（省里老领导 / 组织部线 / 无靠山纯政绩） |
| 目标层 | 五年一届；十年＝两届。路径：连任 → 竞争六品 / 省里平调 / 落马 / 下海 / 转事务官 / 安全着陆 |

**最快轨算术**（总设定：一届＝5 年；低层满 3 年可特批提前考核；**四品及以上禁破格**；吏一转官须届满＋考试＋学院一年）：

| 阶段 | 年龄 | 依据 |
| --- | --- | --- |
| 入职吏三 | 22 | ≥22 岁硬底线 |
| 吏二 | 24 | ≥2 年 |
| 吏一 | 27 | ≥3 年 |
| 吏一 3 年特批转轨＋政治学院 1 年 → 十品 | 31 | 压缩「任满一届 5 年」路径 2 年 |
| 九品正处 | 34 | 十品 3 年特批 |
| 八品副厅 | 37 | 九品 3 年特批 |
| **七品市长** | **40–41** | 八品 3 年特批＋帝国考试（高等级）＋中央组织委员会备案 |

- 默认 **41 岁**；若改为「每级满届不破格」则约 47–48，**不用作默认**。
- 小说顾峥 42 岁七品可作同频参照；玩家不是顾峥。
- 低层破格可被巡视追问——是制度刀，不是设定漏洞。

**`State.NewGame` 全面重写**：初始属性不再是科员三围，而是高级干部画像（战略、执行、人望、法治、经济等五维重新定义与量级）；十年考核逻辑从「评优次数」改为「届中/届终＋巡视＋审计＋舆情＋民生」复合。

### S2.5 核心循环：市长的一周

```
周一  办公厅送达「本周卷宗包」(4–7 件，带时限标签) + 周计划(精力分配)
周二–周四  逐日签批/处置卷宗（每日 1–3 件）+ 可选调研/会商/走动
周五  常务会或常委会（本周决定制度化或被挑战）+ 周评
周末  家庭/私交/学习/暗流（LLM 氛围文案）
月末/季末/年  考核节点、巡视、审计、省里通报
```

- **周计划五槽**（保留结构，改语义）：`签批专注 / 调研摸底 / 会商协调 / 关系走动 / 家庭休整`。槽位影响当日可处理件数、核对加成、关系事件率、体力。
- **快进**：无紧急未办卷宗时可推进；**逾期件、常委会日、剧情链节点必停**。
- **与旧引擎对齐**：`Flow.CollectDue` 顺序可保留；卷宗是「任务」的完全体，剧情链/回响/时钟挂接点不变。

### S2.6 卷宗审核（Papers Please 本体）

#### 数据契约（Core，纯 C#）

```csharp
class Dossier {
  string id;            // 全局唯一
  string kind;          // archetype：routine|deadline|cosign|risk|showcase
  string form;          // 物理形态：请示|会议材料|人事单|财政件|土地件|信访件|突发事件|省交办|巡视整改|协议|对上报告
  string title; string docNo; string org;   // 来文单位（19局/区/省）
  string deadline;      // 游戏日；逾期后果
  List<DossierPage> pages;   // 多页材料：正文、附件表、数据表、签批单
  List<DossierIssue> issues; // 埋雷：数字勾稽/程序瑕疵/口径过期/人情/领导口头指示/时限
  List<DossierOption> options;
  // options 写 effects（复用 Effects：attrs/flags/marks/echoes/rel/clocks…）
}
class DossierIssue {
  string id;            // 可被玩家「核对」发现
  string pageRef;       // 藏在哪一页
  string detectHint;    // 未发现时不剧透；口径手册/关联件可解锁线索
  int severity;         // 1–3；影响合规分与回响
}
```

#### 玩家操作（回合制，无倒计时）

1. **翻页阅读**（程序排版：红头、表格、签批栏）
2. **核对**（有限次数/耗精力）：对数字、对日期、对印章、对口径手册、对关联卷宗
3. **处置**（必选一）：
   - 照准办结
   - 退回补正
   - 请示上级 / 提请常委会
   - 抄送会签（拉 NPC 分担或树敌）
   - 压下缓办（时限风险）
   - （灰）特事特办 / 通融——人情与效率，合规刀口
4. **批示**（可选一句短批示，LLM 可润色，写入档案）

#### 两把尺（仪表盘常驻）

| 尺 | 含义 | 变动 |
| --- | --- | --- |
| **合规分** | 程序与实体合法性 | 埋雷未查出并照准 −；严重事故大 −；主动退回/请示 +小幅 |
| **效率分** | 时限、积压、省里交办完成率 | 逾期 −；积压 >阈值 −；限时件按期 + |

两把尺进 **年度考核、届中鉴定、巡视底稿**；单独「廉洁/人望」等由 marks 与 NPC 关系承载，避免三尺打架。

#### 五骨架映射（兼容旧 TaskGenerator）

| 旧骨架 | 新 archetype | 压力结构 |
| --- | --- | --- |
| 例行 | routine | 低风险，教学与手感 |
| 限时交办 | deadline | 时限标签紧，逾期通报 |
| 协作 | cosign | 必须会签/协调，得罪人或绑人 |
| 有程序风险 | risk | 埋雷密度高，灰区选项 |
| 当众露脸 | showcase | 常委会/媒体可见，人望与政绩可见 |

`TaskGenerator` 进化为 `DossierGenerator`：模板×变量（局名、数字、企业名、人名），保证十年不重样；**高光与教学件手写**。

#### 错误类型（刀子清单）

1. 数字勾稽失败（预算、人次、投资额前后矛盾）
2. 程序瑕疵（文号、越级行文、缺附件、缺印章）
3. 口径过期（用了作废文件）
4. 人情件（亲属/关系企业材料）
5. 口头指示 vs 书面规则冲突（主席/省领导暗示）
6. 时限逾期
7. 连带责任（照准后巡视/审计/事故回溯）

### S2.8 文字体系（手写精品＋LLM 个性）

#### 文风圣经（强制）

- 视角：限制第三人称或「你」，冷、准、具体。
- 一句一义；公文腔与内心腔交替。
- **禁止**：空洞抒情、「你感到」式告诉、四字成语堆砌、选项标签写成说明书。
- **必须**：至少一个具体数字或专名；一个感官细节（纸、烟、灯、声音）；一处权力关系暗示。
- 称谓：严格世界观（市长/主席/局长/署/局/常委会）。

**反例→正例**：

> 旧：「你认真审核了材料，决定同意。」  
> 新：「财政局的追加请示躺在灯下。第 3 页合计栏比正文多了 47 万——墨色还新。你把烟按灭在已经满出来的烟灰缸里。」

#### 内容分层

| 层 | 内容 | 策略 |
| --- | --- | --- |
| L1 手写精品 | 序章、主线链、关键 NPC、结局、教学卷宗、高光卷宗 | 人写精修，进 Content* |
| L2 模板卷宗 | 日常请示/财政/信访等 | DossierGenerator 变量填充，骨架统一 |
| L3 LLM 个性化 | 每日氛围一句、闲谈、周评、家信、批示润色 | 现有 Llm 协议扩展；失败静默回退 |

#### 序章重写（七品）

三幕，而非一段话：

1. **省城谈话**——谁送你上任、说了哪句听不懂的话。
2. **第一次常委会**——11 席权力地形一眼建立；主席第一句敲打。
3. **第一份卷宗**——教学件：含一个可查出的数字雷；签完钩子（十年后回望）。

出身/债务/家庭在三幕内用选项落 marks，不单开「童年编年」。
